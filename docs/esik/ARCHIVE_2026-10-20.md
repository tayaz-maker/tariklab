# Kıyı Eşiği archive

Kıyı Eşiği leaves the active catalogue, TR/EN/PL Resources entries and active discovery. Existing /oyna/esik and /games/esik/ remain playable with the same game. The portal wrapper adds the existing localized archive notice and noindex; no unrelated replacement-game link is presented. No game, asset, dependency or save source is deleted.

Useful systems retained for future source-grounded adaptation:

- sim.js: deterministic legal moves, pure previews, access faults, delayed ramps, distinct endings and validated v1 serialization.
- save-store.js: primary/backup selection and eight bounded corrupt-record recovery slots; failed writes retain previous data. Useful as a storage-boundary reference, with each future consumer's own key/schema rules.
- map-model.js and map-pixi.js: simulation/view separation, SVG fallback and optional Pixi projection. Source is preserved without importing a coast metaphor into another game.
- app.js, CSS, original entry, Polish dictionary and source provenance remain. Shared Pixi adapter/vendor are retained for HANEDANIAN, DEVLET, Racon and the existing IHTILAL archive.

No new coast feature, migration, version bump, storage reset or engine transfer. Existing primary, backup and recovery bytes survive portal navigation. Six real Chromium cases verify catalogue/Resources exclusion, archived routing, original progress resumption, a legal move and reload, recovery preservation and overflow/errors in TR/EN/PL × 1280/390. Existing coast save recovery tests remain unchanged and required. IHTILAL archive tests continue to cover its independent ten-key save contract.
