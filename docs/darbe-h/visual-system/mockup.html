Logo

A seal ring, a geometric D whose chamfer is a dossier-tab corner, and one diagonal crack cutting through both: the stamp that breaks the order. It is built only from paths, so no font licence applies. The favicon cut drops the perforation and widens the crack for 16 px.

Anatomy

  1. Kind rail: the colour band, glyph and word (GÖREVLİ, EMİRNAME or İHTAR). This is the only thing you need to read at board size. Colour is never the only signal.
  2. Rank chip: K4 means kademe 4, in paper-on-ink numerals. Emirname and İhtar show their timing instead (ANLIK, HIZLI, KALICI, TEÇHİZ, SAHA, KARŞI).
  3. Name: at most 2 balanced lines, and never truncated in the inspector.
  4. Art window with the bureau stamp (MHT, BRF, …): the series, so combo families read at a glance.
  5. Effect slip: dark ink on paper at 14:1 contrast. Tags come first: −650 KP for the cost, then the verb (ÇAĞRI, YOK ET, KONTROL…), then the text.
  6. Footer: tabular ATK/DEF for Görevli (the same words the effect texts use), with ▲/▼ and colour when modified. Other kinds show the resolution verb.

Kinds

The same slots on every card, so the eye learns one layout. The kind changes the rail, glyph, footer and rank/timing chip. Everything else stays in place.

States

Each state has a label, shape or position cue besides colour, and a matching aria-/data- attribute that duel-core already computes.

Sizes

One component with container queries. Below 110 px wide (the board), the effect slip, kind word and bureau stamp fold away, and the rail, rank, name and stats stay.

What the player always sees:

  1. what is selected: the lifted card with the SEÇİLİ tab, repeated by name in step 1;
  2. what it will do: a forecast strip computed from the same projection the AI uses (damage, destroy, KP change), shown before confirming;
  3. what comes next: the numbered step bar, with the current step outlined. Valid targets carry the dashed HEDEF frame, and everything else dims.

After resolution, the result sits on the card for about 900 ms (−400 KP, a YOK EDİLDİ stamp) before it moves to the grave, so cause and effect stay together.
