# Çete Savaşları — terminologia PL (robocza)

| Turecki termin | Polski odpowiednik | Kontekst |
| --- | --- | --- |
| Racon | racon | Zachowany jako nazwa własna ulicznego kodeksu i części nazwy gry; przy pierwszym wyjaśnieniu warto opisać jego sens. |
| Çete | gang | Organizacja przestępcza; marka Çete Savaşları pozostaje bez zmian. |
| Ekip | ekipa | Współpracownicy gracza; pojedyncza osoba to członek lub członkini ekipy. |
| Mahalle | dzielnica | Lokalna okolica; nazwy własne dzielnic pozostają bez zmian. |
| Kasa | kasa | Miejsce przechowywania pieniędzy; fundusz łapówek określa się osobno. |
| Nüfuz | wpływy | Siła oddziaływania w danym kontekście; nie zastępuje reputacji. |
| İtibar | reputacja | Osobny wskaźnik reputacji. |
| Görev / icraat | zlecenie | Czynność podejmowana przez gracza; zależnie od zdania również robota. |
| Sözleşme | kontrakt | Konkretna umowa z premią i terminem. |
| Bölge / semt | dzielnica lub obszar | Dzielnica w nazwach miejsc, obszar gdy chodzi ogólnie o teren. |
| Borç | dług | Zobowiązanie do spłaty; nie mylić z należnością. |
| Gelir | dochód | Wpływ pieniędzy; przy regularnych płatnościach można podać okres. |
| Emniyet / ısı | presja policji | Wskaźnik uwagi policji; zachować spójność z HUD. |

Dokument opisuje zamierzone użycie i nie jest dowodem pełnego pokrycia. Nazwy własne, waluta TRY oraz liczby i reguły gry pozostają bez zmian. Wymagana jest kontrola pozostałych ekranów i polskich form liczebnikowych.
