## What the live page plays

`/games/ihtilal/index.html` loads `solo-app.js`. The playable game is a one-seat period desk:

- seven invented administrative basins
- capacity, trust, information, tension
- immediate numbers and a delayed echo on a later period
- a fracture choice on period 4
- four endings: record held, tired order, fracture, hollow desk

No real person, party, office-holder, or dated historical incident is named in this layer. Basin names are terrain labels written for this desk. The map is a schematic of those basins, not an official border and not traced from a published map.

## What is not a source

- No board-game rulebook, card, die, election track, or two-player scoring table was copied.
- No third-party map art, flag, emblem, or screenshot is used.
- The older card catalog under `public/games/ihtilal/cards.js` remains in the repository for its existing unit tests. The live page does not load it.

## Save

The solo desk uses `tariklab.ihtilal.solo.v1`. It does not read or migrate `tariklab.ihtilal.v1` card slots. Opening the file starts a solo state. That is a deliberate reset, not a silent conversion of an old match.
